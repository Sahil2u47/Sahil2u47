<summary><b>📦 Multi-Vendor E-commerce Platform</b></summary>

**Scalable monolithic Spring Boot e-commerce platform supporting multiple vendors and customers with role-based access control, secure JWT authentication, and optimistic locking for concurrent operations.**

A comprehensive e-commerce platform enabling admins to manage vendors, vendors to list and sell products, and customers to browse and purchase. Architected with Spring Boot using `@Inheritance(strategy = InheritanceType.JOINED)` for flexible role-based user management (Admin/Vendor/Customer). Implemented Spring Security with JWT tokens, MySQL with JPA/Hibernate for ORM, optimistic locking via `@Version` for handling concurrent updates, and soft deletes via isActive flags for data integrity. Automated business processes using `@Scheduled` annotations. Currently in Postman testing phase with Razorpay payment integration planned.
